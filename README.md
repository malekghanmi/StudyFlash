## 🚀 Quick Start 

### Step 1 — Prerequisites
```bash
# Make sure you have Flutter installed
flutter --version   # Must be 3.x+

# Install FlutterFire CLI
dart pub global activate flutterfire_cli
```

### Step 2 — Clone & Install
```bash
cd studymate
flutter pub get
```

### Step 3 — Create Firebase Project

1. Go to https://console.firebase.google.com
2. Click **Add Project** → name it `studymate`
3. Enable **Authentication** → Sign-in methods:
   - ✅ Email/Password
   - ✅ Google
4. Create **Firestore Database** → Start in test mode
5. Go to **Project Settings** → copy your config

### Step 4 — Connect Firebase to Flutter
```bash
# In the project folder:
flutterfire configure
# Select your project → select iOS + Android
# This generates lib/firebase_options.dart automatically ✅
```

### Step 5 — Get Gemini API Key (Free!)

1. Go to https://aistudio.google.com/app/apikey
2. Create API key (free tier is enough)
3. Open `lib/features/ai/screens/ai_generator_screen.dart`
4. Replace line 13:
```dart
const _geminiKey = 'YOUR_GEMINI_API_KEY'; // ← paste your key here
```

### Step 6 — Run the App
```bash
flutter run
```

## 🛠️ Common Issues

**`firebase_options.dart` not found?**
→ Run `flutterfire configure` in the project root

**Google Sign-In not working on Android?**
→ Add your SHA-1 to Firebase: `keytool -list -v -keystore ~/.android/debug.keystore`

**Gemini returning error?**
→ Check your API key in `ai_generator_screen.dart` line 13
